# 인보이스 스튜디오 · Invoice Studio

견적서·인보이스를 만들고 **A4 PDF로 인쇄·저장**하는 정적 웹 도구.
cardnews-studio, blog-post-studio와 한 세트다.

실제 발행 문서(D 드라이브 `사업관련 - 견적서 인보이스 사업자 등`, `작업폴더/0 견적`의
견적서·인보이스 PDF/XLSX)의 레이아웃과 계산 규칙을 그대로 재현했다:

- 좌상단 타이틀 + 클라이언트 + 발송일 / 우상단 공급자 테이블(상호·등록번호·주소·전화·이메일)
- 금액 밴드 `견적금액(공급가액 + 세액)` / `금액(공급가액 + 세액)`
- 품목 테이블: 품명(+하위 상세 줄) / 공급가액 / 세액 / 합산 / 수량 / 총합산금액(강조색)
- 참고 사항, 기타(계좌: 은행 / 계좌번호 / 예금주), 견적서 유효기간

설계 철학도 세트와 같다: **입력(품명·단가·옵션)은 사람, 계산·레이아웃·번호는 코드.**

- 품목은 공급가액(단가)과 수량만 입력 — 세액 10%, 합산, 총합산금액, 문서 합계는 파생
- 부가세 포함 토글(끄면 공급가액 = 합계), 원천징수 3.3% 토글(공급가액 기준, 실수령액 표시)
- 문서번호 자동 부여: `Q2026-001` / `I2026-001` (유형+연도+순번, 복제 시 새 번호)
- 회원가입·크레딧 같은 계정 기능 없음 — 전부 브라우저 안에서 끝난다 (요청에 따라 의도적으로 제외)

## 실행

```bash
python -m http.server 8020 --directory invoice-studio
```

GitHub Pages / Netlify / Vercel / CloudBase 정적 호스팅에 폴더째 올려도 동작한다.

## PDF 출력

헤더의 **"PDF로 인쇄"**(또는 Ctrl+P) → 브라우저 인쇄 대화상자에서 "PDF로 저장".
인쇄 CSS(`@page A4`)가 앱 UI를 숨기고 문서(paper)만 A4에 정확히 맞춰 출력한다.

## 세트 구성

| 앱 | 역할 |
|---|---|
| **cardnews-studio** (`../cardnews-studio`) | 인스타그램·스레드용 카드뉴스 7장 |
| **blog-post-studio** (`../blog-post-studio`) | 블로그 포스트 + WordPress 발행 패키지 |
| **invoice-studio** (이 앱) | 견적서·인보이스 발행 (A4 PDF) |

세 앱이 같은 Apple Reference Design System 토큰(Fog Canvas `#f5f5f7`, Primary `#0071e3`,
pill 버튼, 18px 카드)을 공유하고, 각각 "불러오기/JSON 저장"으로 문서를 주고받을 수 있다.
공급자(내) 정보는 세트 공용 키 `studio-suite-sender-v1`에 저장해 두어 나중에 세트 통합 시
브랜드 설정과 합칠 수 있게 했다.

## 기능

| 기능 | 설명 |
|---|---|
| 문서 유형 | 견적서(유효기간 표시) / 인보이스(계좌 강조) — 언제든 전환 |
| 품목 | 품명 + 상세 줄(번호 매긴 내역) + 공급가액(단가) + 수량 → 세액·합산·총합산 자동 |
| 금액 옵션 | 부가세 10% 포함/제외, 원천징수 3.3%(사업소득) — 실수령액까지 표시 |
| 문서번호 | `Q2026-001` / `I2026-001` 자동 순번, 복제 시 새 번호 |
| 공급자 정보 | 상호·등록번호·주소·전화·이메일·기본 계좌 — 모든 문서 공통 |
| 참고사항 | 줄 단위 자유 입력 (작업기간·수정정책 등 — 실제 문서의 패턴) |
| 내보내기 | PDF 인쇄 / 문서+공급자 JSON 저장·불러오기 |
| 자동저장 | localStorage(`invoice-studio-v1`) 즉시 저장 |

## 문서 JSON 스키마

```jsonc
{
  "type": "quote" | "invoice",
  "number": "Q2026-001",
  "clientName": "주식회사 예시",
  "clientContact": "담당자 / 전화 (선택)",
  "issueDate": "2026-10-02",
  "validUntil": "2026-10-16",        // 견적서만
  "vatEnabled": true,
  "withholding": false,
  "withholdingRate": 3.3,
  "items": [
    { "name": "품명", "details": ["1. 상세", "2. 상세"], "supply": 200000, "qty": 1 }
  ],
  "notes": ["줄1", "줄2"],
  "bank": "신한 / 000-0000-000000 / 예금주",
  "etc": "기타 문구"
}
```

## 구조

```
invoice-studio/
├── index.html
├── assets/app.css     # 세트 공통 토큰 + A4 문서(paper) 스타일 + 인쇄 CSS
└── js/
    ├── app.js         # UI (레일·문서 렌더·편집기·모달·인쇄)
    ├── store.js       # 문서 컬렉션 + 공급자(세트 공용 키) + 자동저장
    ├── calc.js        # ★ 금액 계산 (세액 10% / 원천징수 3.3% / 문서번호)
    ├── sample.js      # 샘플 견적서·인보이스 각 1건
    └── util.js        # 포맷(₩, 날짜)·다운로드 유틸
```

## 폰트

UI는 Pretendard(변수 폰트, 자체호스팅, SIL OFL 1.1)를 사용하며 자간 -0.02em 보정을 적용했다.
